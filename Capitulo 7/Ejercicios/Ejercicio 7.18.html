7.18

Sin ejecutar la siguiente secuencia de comandos, determine lo que imprime: 

var fila = 10;
var columna;

while ( fila >= 1 )
{
   columna = 1;
   document.writeln( "<p>" );

   while ( columna <= 10 )
   {
      document.write( fila % 2 == 1 ? "<" : ">" );
      ++columna;
   } // fin de while

   --fila;
   document.writeln( "</p>" );
} // fin de while

La secuencia de comandos imprime 10 renglones (uno por cada valor de fila, de 10 a 1), con 10 símbolos cada uno. Los renglones alternan entre > y <, empezando con >:
