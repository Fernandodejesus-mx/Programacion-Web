Ejercicio 6.4 - Identifique y corrija errores

a)

if ( c < 7 );
   window.alert( "c es menor que 7" );

Error: hay un punto y coma después de la condición, lo que deja vacío el cuerpo del if (el alert se ejecutaría siempre).

Corrección:

if ( c < 7 )
   window.alert( "c es menor que 7" );

b)

if ( c => 7 )
   window.alert( "c es igual o mayor que 7" );

Error: el operador => no es un operador relacional; el correcto es >=.

Corrección:

if ( c >= 7 )
   window.alert( "c es igual o mayor que 7" );
