Ejercicio 6.14 - Orden de evaluación

a) x = 7 + 3 * 6 / 2 - 1;

  1. 3 * 6 = 18
  2. 18 / 2 = 9
  3. 7 + 9 = 16
  4. 16 - 1 = 15

x = 15

b) x = 2 % 2 + 2 * 2 - 2 / 2;

  1. 2 % 2 = 0
  2. 2 * 2 = 4
  3. 2 / 2 = 1
  4. 0 + 4 = 4
  5. 4 - 1 = 3

x = 3

c) x = ( 3 * 9 * ( 3 + ( 9 * 3 / ( 3 ) ) ) );

  1. ( 3 ) = 3 (paréntesis más interno)
  2. 9 * 3 = 27
  3. 27 / 3 = 9
  4. 3 + 9 = 12
  5. 3 * 9 = 27
  6. 27 * 12 = 324

x = 324
