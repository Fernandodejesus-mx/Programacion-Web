Verdadero o Falso

a) Un documento de HTML5 válido no puede contener letras mayúsculas en nombres de elementos.

Falso. HTML5 permite utilizar letras mayúsculas en los nombres de los elementos. Sin embargo, se recomienda utilizar minúsculas.

b) Los documentos de HTML5 pueden tener la extensión de archivo .htm.

Verdadero. Los documentos HTML5 pueden utilizar las extensiones .htm y .html.

c) &less; es la referencia a entidad de carácter para el carácter menor que (<).

Falso. La referencia correcta para el carácter menor que (<) es &lt;.

d) En un documento de HTML5 válido, <li> puede anidarse dentro de etiquetas <ol> o <ul>.

Verdadero. El elemento <li> se utiliza para representar los elementos de una lista ordenada (<ol>) o desordenada (<ul>).
