Complete las siguientes oraciones

  1. El elemento __________ inserta una regla horizontal.

    Respuesta: hr

  2. Para marcar un superíndice se utiliza el elemento __________.

    Respuesta: sup

    Para marcar un subíndice se utiliza el elemento __________.

    Respuesta: sub

  3. El elemento de encabezado menos importante es __________.

    Respuesta: h6

    El elemento de encabezado más importante es __________.

    Respuesta: h1

  4. El elemento __________ marca una lista desordenada.

    Respuesta: ul

  5. El elemento __________ marca un párrafo.

    Respuesta: p

  6. El atributo __________ en un elemento input inserta un botón que, cuando se presiona, restablece el contenido del formulario.

    Respuesta: type="reset"

  7. El elemento __________ marca una fila de una tabla.

    Respuesta: tr

  8. Los __________ se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.

    Respuesta: Asteriscos
